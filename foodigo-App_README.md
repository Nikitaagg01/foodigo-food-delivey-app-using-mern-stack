# 🍔 Foodigo – Food Delivery App

A full-stack food delivery application built with the **MERN stack**, featuring RESTful APIs, admin/user dashboards, and optimized backend performance.

**Team Size:** 2 | **Duration:** June 2025 – July 2025

## ✨ Features

- RESTful APIs handling 5K+ mock requests/day with stable performance
- Query optimization and caching for 30% faster backend response times
- Admin dashboard for order and inventory management
- User dashboard for browsing, ordering, and tracking food
- CI/CD pipeline integration, cutting deployment time by 40%

## 🛠️ Tech Stack

**Frontend:** React.js, Tailwind CSS
**Backend:** Node.js, Express.js
**Database:** MongoDB
**Tools:** Postman, Git, CI/CD

## 📊 Impact

| Metric | Improvement |
|---|---|
| Backend response time | 30% faster |
| Manual order handling | 25% reduction |
| Deployment time | 40% faster |

## 🚀 How to Run

1. Clone the repository
   ```bash
   git clone https://github.com/Nikitaagg01/foodigo-App.git
   cd foodigo-App
   ```
2. Install dependencies for backend and frontend
   ```bash
   npm install
   ```
3. Set up environment variables (`.env`) for MongoDB URI and other configs
4. Start the development server
   ```bash
   npm start
   ```
