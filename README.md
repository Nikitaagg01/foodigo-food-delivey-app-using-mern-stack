# Foodigo - MERN Food Delivery Website 🍔

Foodigo is a full-stack Food Delivery Web Application built using the **MERN Stack**.
The project includes separate sections for:

* Frontend (User Side)
* Backend API
* Admin Panel

Users can browse food items, add products to cart, place orders, and manage their accounts, while the admin can manage food items, orders, and users.

---

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash id="r3u2wy"
git clone - https://github.com/Nikitaagg01/foodigo-food-delivey-app-using-mern-stack
```

---

## 2️⃣ Install Dependencies

### Frontend

```bash id="4mblvn"
cd frontend
npm install
npm run dev
```

### Backend

```bash id="jlwm11"
cd backend
npm install
node server.js
```

### Admin Panel

```bash id="jlwm22"
cd admin
npm install
npm run dev
```

---

# 🔐 Environment Variables

Create a `.env` file inside backend folder:

```env id="jlwm33"
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
PORT=5000
```
